PARADISE
A cinematic web experience exploring Lana Del Rey's albums through interactive vinyl records and dreamy worlds.

Features
9 unique album worlds inspired by different Lana Del Rey eras
Interactive vinyl record player with song playback
Dynamic song discovery powered by YouTube Data API
Atmospheric visuals, drifting memories, and floating text
Cinematic transitions between albums and worlds
Responsive experience for desktop, mobile
Persistent local storage for favorites, notes, and memories
Dreamlike UI inspired by old Hollywood, Americana, and late-night nostalgia
Built With
HTML5
CSS3
JavaScript (Vanilla JS)
GSAP
YouTube Data API v3
LocalStorage API
Responsive Design Principles
About This Project
Built as a vibe-coded project, the experience was designed and developed with the assistance of AI tools.

Rather than being a traditional music website, PARADISE.EXE aims to feel like a cinematic dream that users can explore.
