# PARADISE.EXE

**A cinematic web experience exploring Lana Del Rey's albums through interactive vinyl records and dreamy worlds.**

PARADISE.EXE is an experimental music-inspired web experience built around Lana Del Rey's different eras. Instead of behaving like a traditional music website, it is designed to feel like a cinematic dream archive where each album becomes its own visual world.

## Features

- 9 unique album worlds inspired by different Lana Del Rey eras
- Interactive vinyl record player with song playback
- Dynamic song discovery powered by the YouTube Data API
- Atmospheric visuals, drifting memories, and floating text
- Cinematic transitions between albums and worlds
- Responsive experience for desktop and mobile
- Touch-friendly interactions for mobile devices
- Persistent local storage for favorites, notes, and memories
- Dreamlike UI inspired by old Hollywood, Americana, late-night nostalgia, and analog film aesthetics
- Distinct visual color identity for every album era

## Built With

- **HTML5**
- **CSS3**
- **JavaScript**
- **GSAP**
- **YouTube Data API v3**
- **YouTube IFrame Player API**
- **LocalStorage API**
- **Responsive Design Principles**
